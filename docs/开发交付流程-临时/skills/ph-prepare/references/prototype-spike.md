# 原型与技术试验

只有试验结果会改变方案时才做。已有足够证据就直接规划。

## 开始前

写清待验证问题、最小真实输入、成功与失败判据、预算、可写位置和外部服务权限。只读计划中需要写入时，先走宿主许可流程；不能通过提前批准未经验证的产品方案换取写权限。

## 取得结果

- 交互原型只展示需要比较的布局或路径，虚构数据明确标记。按宿主浏览器和视觉规则实际查看，由主 Agent 展示真实产物并取得影响方案的选择。
- 技术试验在明确版本和环境运行最小输入，记录输出和结论。一次样例成功不能证明全部兼容。

得到决定性证据、达到预算或碰到权限边界就停止。回传问题、结果、证据、限制和对方案的影响，不堆全部日志。

## 写回方案

把结论与真实决定记入已有任务记录。探索代码不自动成为产品代码；纳入实现前检查授权、质量、测试和维护成本。正式验收使用正式成果，试验资源按已有保留和清理权限处理。
