# 检查方案

检查方案是否足以实施，不为普通任务安排固定评审角色。

## 检查重点

- 每条需求都有可观察的结果和验证方法。
- 方案已核实相关实现、调用方和可复用能力。
- 任务位置、依赖和完成条件明确，下一步无需猜接口或验收要求。
- 与本次相关的异常、权限、数据和兼容问题已有处理办法。
- 未确定的事实列为假设，所需决定和权限没有被写成已取得。

例如，空结果导出方案不仅要写“不报错”，还要确定文件内容，以及非空格式和权限是否保持。

## 谁来检查

项目强制要求优先。局部低风险方案可自审；安全边界、数据迁移或重要兼容变化，安排实现者以外的执行者或人类评审。用户禁止委派时不派代理；所需独立评审缺失则如实记录，不以自审替代。

提供目标、非目标、标准、核实位置、方案和待决项，授予只读调查范围。无需共享整段推理，也不要求必须找到问题。

每条问题写清缺失条件、可能后果、依据和建议；猜测注明待查，风格偏好不算阻断。主 Agent 核实后补方案，超出原范围的建议另列。没有发现只说明已查范围与限制，不保证方案不存在缺陷。
