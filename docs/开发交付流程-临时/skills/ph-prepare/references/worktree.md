# 选择工作位置

只有需要写入或切换工作区时才读本文件。沿用项目 Git 规则，不另建一套分支协议。

1. 核实项目目录、当前分支和原有修改，包含暂存、未暂存、新增文件及相关 ignored 资源。非 Git 项目记录实际目录即可。
2. 项目允许当前目录工作时直接沿用，未知改动保持原状。不为获得干净工作区自动提交、清空或搬走用户内容。
3. 确需隔离时，核实创建分支或 worktree 的授权与能力。worktree 只隔离文件，不隔离端口、数据库和外部服务。
4. 已有工作区先核对任务、路径、分支与会话身份，匹配后恢复。登记冲突先只读诊断，不猜测修复。

## PH 项目

[条件清单](dependencies.json) 的路径相对目标项目根目录。需要创建 PH worktree 时，必须满足项目对 `ph-worktree-enter` 的调用要求，再按该技能检查、预演和创建。

只调用 ph-prepare 不等于已调用其他技能；缺少调用权限就说明所需入口，不直接执行内部脚本绕过。WIP 确认与安全检查沿用原技能。

准备完成不要求已创建工作区；必须隔离但尚未具备条件时，在方案中列出阻断。后续提交、合并或清理不属于准备阶段的自动动作。
