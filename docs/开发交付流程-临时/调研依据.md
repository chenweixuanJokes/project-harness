## 已纠正的细节

1. [Codex 官方源码](https://github.com/openai/codex/blob/main/codex-rs/ext/skills/src/render.rs)中的 2% 是已知上下文窗口的元数据 token 预算，8,000 字符是未知窗口回退。不是正文上限，也不用于本套件自动裁剪。
2. [Claude Skills](https://code.claude.com/docs/en/skills)的每技能 5,000、合计 25,000 token 是压缩后重新附加预算，不是文件合法性限制；500 行是建议。具体数字仅为当前文档事实。
3. geminicli.com 不是因域名不同就属于第三方。官方 README 的 “our documentation” 链接已纠正研究报告自身错误。`--consent` 跳过安装确认，不能据此跳过运行时激活。
4. ZCode 的 1024 字符（description 超限丢弃）、250 字符（清单描述摘要）、100KB（正文截断）含义不同。当前入口保持短描述，不把这些限制施加给所有宿主。未在官方内置清单找到 Superpowers，不等于证明任何版本均不存在。
5. Spec Kit 测试默认可选，constitution 可增加要求；不能称为所有任务内置强制 TDD。Kiro 的 PBT 也有可选性和产品端差异。
6. [Kiro 2025-08 价格文章](https://kiro.dev/blog/understanding-kiro-pricing-specs-vibes-usage-tracking/)的 spec/vibe 双费率是历史政策，[当前价格页](https://kiro.dev/pricing/)已使用 credits。本套件不引用五倍计价论证现状。
7. DeepSeek 模型名、采样参数和 reasoning_content 规则存在版本变化；9 月 14 日“继续提供”来自价格页，不是停服日期。与技能执行步骤无直接关系，故不固化。
8. Kimi 官方对长工具链和 Heavy 并行的描述是模型能力宣传，不证明应采用固定并行数量或嵌套深度。单个 discussion 不能证明公司没有 SDD 规范。

## 效果与事故证据

- [Hill Zenodo 记录](https://zenodo.org/records/19432099)与 ESEM 程序摘要支持存在一项 SDD 观察研究；版本间 PR 数量不同，本轮未读取 PDF 正文。不以摘要证明 SDD 普遍有效或无效，也不接受“没有任何厂商提供实证”“这是最大研究”这类未独立核实的全称判断。
- [METR 2026-02 更新](https://metr.org/blog/2026-02-24-uplift-update/)解释后续估计的测量与选择偏差，置信区间跨零。采用“效果应测量”的方法，不把速度百分比当本套件目标。
- [Microsoft CLI agent 研究摘要](https://arxiv.org/abs/2607.01418)不是 SDD 研究。Management Science 的多公司 RCT 本轮仅经摘要聚合取得信息，未读出版商正文，不用于因果外推。
- [Replit 官方数据库文章](https://replit.com/blog/introducing-a-safer-way-to-vibe-code-with-replit-databases)确认开发/生产隔离改进，不直接证实全部事故细节。[Amazon 声明](https://www.aboutamazon.com/news/aws/aws-service-outage-ai-bot-kiro)反驳媒体归因；不能单方面写成已证实的 AI 致障因果。
- [菜鸟演讲报道](https://news.qq.com/rain/a/20260917A0D3M000)是媒体转述，代码贡献率与交付周期不是同一指标；不同报道有不同数字。不设“AI 写代码占比”验收目标。

## 仍未核实，不作为实施前提

OpenAI agent loop 原文抓取 403；撤回“官方建议冻结模型、工具集和工作目录”。Gemini 参数与 thought signatures、Antigravity 审批页面抓取超时；浏览器路径被计划模式拒绝，未偷偷解除权限。Codex 部分目录保护与审批值混有历史、平台特例；不声称 `.agents` 普遍受沙箱保护。部分论文全文、员工联署数字和事故原帖未取得。

前轮材料中新增的 DeepSeek Harness、托管平台等来源不在本轮已取得的核验证据内，继续保留为历史线索，而不标为本轮已确认。未知内容不因被多次转述变成确定事实。

## 本套件实际选择

四入口、自包含目录、少量重复关键边界、单一任务记录和轻量/标准路径，均是本套件工程选择，不是厂商统一标准。静态检查、作者演练与独立模型评估分别报告；本轮没有独立模型对照，不宣称成功率或成本改善。
