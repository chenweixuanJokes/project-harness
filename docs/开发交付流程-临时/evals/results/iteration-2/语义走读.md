## 局限

新增文件验收场景需要评估方提供真实可达文件；本轮没有真实用户回答。事件 JSON 只用于模拟决策，没有实际合并或发布。当前作者已知规则和场景，不能据此证明独立执行稳定性或新稿优于旧稿的成功率。
