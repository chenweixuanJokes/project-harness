# 后端回归测试规范

Last verified: <填写：YYYY-MM-DD>

使用时机：合入共享基线、合入主分支前、重构或依赖大版本升级后跑后端回归门禁时读本文。

> 回归的本质：把后端单元测试全部跑一遍，再把后端全部冒烟用例（含接口用例）跑一遍。跨端口径与阻塞语义在 [门禁规范](../门禁规范.md)；命令的单一源在 [自测规范](../../后端规范/自测规范.md)；冒烟用例登记在 [后端测试用例](./后端测试用例/_模板.md) 目录。本仓库无后端时，本文标不适用。

## 1. 触发条件

合入共享基线、合入主分支前、重构或全局改动、依赖大版本升级，任一命中必须跑后端回归；不得以「行为未变」「改动很小」为由跳过。

## 2. 组合与顺序

| 步骤 | 内容 | 通过标准 |
| --- | --- | --- |
| 1. 全量单元 | 该端全部单元测试（命令见 [自测规范](../../后端规范/自测规范.md)） | 全量全绿；失败即终止，不继续冒烟 |
| 2. 全部冒烟 | [后端测试用例](./后端测试用例/_模板.md) 目录登记的全部冒烟用例（含 `.http` / 接口用例），**无分档，一律全跑** | 每条用例断言通过且证据可查 |

## 3. 失败处理

- 任一步失败即阻塞合入 / 发布。
- 修复后从失败的那一步起重跑整个组合（全量单元 + 全部冒烟），不得只重跑失败的单条用例。
- 重跑仍偶现失败，按 [稳定性规范](../稳定性规范.md) 的 flaky 流程处置，不当通过。

## 4. 证据

两步各留证据（报告路径或用例内「证据记录」，要求见 [用例规范](../用例规范.md) 第 6 节）；没有证据的回归不算跑过。
