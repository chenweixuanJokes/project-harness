## 2. 用例粒度与自包含

- 一文件一用例集（一个 domain 或一组相邻接口），文件内步骤可独立重放。
- 每个用例文件自包含认证链路（登录 → 凭证 → 业务断言），不依赖其它用例留下的会话或数据。
- 用例之间不共享执行顺序假设；脏数据自清理（清理字段见 [用例规范](../用例规范.md)）。

## 4. 断言与证据

- 业务断言至少包含：HTTP 状态、业务返回码（错误码表见后端 [技术规范](../../后端规范/技术规范.md) 第 5 节）、关键字段。
- 执行后证据（报告路径或用例内「证据记录」）必须可查；没有证据不算通过。
- 缺陷先用同一用例复现，修复后再用同一用例验证；断言失败即失败。
