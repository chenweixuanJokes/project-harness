# acceptance-template.md（验收标准与记录）

> 书写参考，不是规则。写入功能目录 `acceptance.md`。本文件只记录 requirement.md/change.md 中需要用户判断的成果标准及真实结论。passed 状态只能由技能在用户真实验收后用 `ph_sdd.py mark --artifact acceptance --status passed` 记录，并附用户决定或证据文件。
>
> 技术正确性、回归是否通过等标准由智能体在 verify-plan.md/verification.md 中覆盖，不因编号为 AC-n 就要求用户重复验证。保留已有编号，明确其责任和证据落点；用户只判断已准备好的业务成果。

## 验收前提（缺一则验收尚未开始）

- 环境与代表数据已准备：验收所在环境可用，数据能代表真实使用。
- 真实入口已知：用户从哪里进入并操作。
- 主流程已明确：用户按什么步骤走到成果。
- 预期有用成果已对照：AC-n 描述的结果用户确实需要。
