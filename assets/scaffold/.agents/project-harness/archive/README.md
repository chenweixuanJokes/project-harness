# archive/

只读历史区：保存升级前原件、历史资料与已完成需求的归档快照，不作为活动规则、运行入口或现行文档。恢复历史内容属于单独操作，不覆盖当前文件。

| 子目录 | 内容 |
| --- | --- |
| `features/` | 已归档需求的只读快照（`<编号>/<UTC 时间戳>/`）与追加式索引 `index.json`，由 `ph_sdd.py archive` 写入（目录在首次归档时创建）；活动记录保留在 `../specs/`，引用不断链 |
| `constraints-history/` | 旧版约束与流程的历史原件，见 [意图与访谈](./constraints-history/意图与访谈.md) |
| `legacy-backup/` | init / 升级覆盖或移出前的原文快照，见其目录 README |
| `memory/` | 已合并的旧版记忆原件，见其目录 README |

需求归档时，受影响的项目事实已同步到 `../documents/`，已验证可复用冒烟用例登记进 `../constraints/` 的前端 / 后端测试用例库；本区只保存历史，快照正文不再更新，重复归档追加新快照不覆盖旧快照。
