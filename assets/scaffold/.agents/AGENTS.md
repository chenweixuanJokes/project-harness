# 项目约束入口

本文件 `.agents/AGENTS.md` 是约束入口的规范源；不要修改厂商适配副本。

## 工作前必读

开始需求分析、规划、实现、验证或维护前，读取 `project-harness/constitution.md`（项目宪法）。按宪法中每个约束文件声明的适用场景，打开相关正文后再执行；不能只读目录或把链接列表当成已遵守约束。

宪法或所需约束缺失、相互冲突时，先核实并报告，不凭模板、历史归档或记忆补造现行规则。

## 基本要求

- 先核实当前代码与项目事实，只修改任务必要内容。
- 明确验收目标并执行对应验证，失败或未验证必须如实说明。
- 保留用户内容和已有修改；提交、推送、发布及破坏性动作遵循当次授权。
- 记忆和历史归档仅供参考，不构成现行约束或执行授权。

目录用途与项目资料入口见 [PH 使用说明](project-harness/README.md)。
